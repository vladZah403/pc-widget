**Download:** `PC-Monitor.zip` below → unpack anywhere → run `PC-Monitor.exe`.
If you have 1.2, the widget shows "Version 1.3 is out" — a click opens this page. From 1.3 on, updates install in one click.

## New
- **Update in one click** — the widget downloads the new version, checks its SHA-256 against GitHub's and swaps it in after a restart; if anything fails, the old version starts again
- **Settings window** with tabs instead of the long menu (right-click → "Settings…")
- **Cores** — a bar per logical processor
- **FPS counter**: 1% low and a frame-time graph where stutters are red
- **Fans** — speeds, when the PC reports them
- **Dims itself** while a game or a fullscreen video is in front
- **Custom colours** — a gradient between two colours you pick
- **Size** 100 / 125 / 150 %
- 36 automated tests, run by GitHub before every build

## Новое
- **Обновление в один клик** — виджет сам скачивает новую версию, сверяет SHA-256 с GitHub и подменяет себя; если что-то пошло не так, запускается старая версия
- **Окно настроек** с вкладками вместо длинного меню (ПКМ → «Настройки…»)
- **Ядра** — полоска на каждый поток процессора
- **FPS**: 1% low и график времени кадра, фризы — красные
- **Вентиляторы** — обороты, если компьютер их отдаёт
- **Тускнеет** в играх и при видео на весь экран
- **Свои цвета** — переход между двумя выбранными цветами
- **Размер** 100 / 125 / 150 %
- 36 автотестов, GitHub прогоняет их перед каждой сборкой
