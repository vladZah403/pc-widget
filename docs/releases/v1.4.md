**Download:** `PC-Monitor.zip` below → unpack anywhere → run `PC-Monitor.exe`. If you have 1.3.2, just click "update ↻" in the widget.

## New
- **FPS in any game**: besides DirectX 10–12, the counter now sees DirectX 9 (Terraria), OpenGL (Minecraft, STALCRAFT) and Vulkan games. Frames are taken from the kernel graphics driver's own event for every presented frame (measured on a real PC: exactly one per frame), filtered by Windows before it reaches the program — no extra CPU load.

Note: Windows doesn't let any program draw over a game in *exclusive* fullscreen. If the counter doesn't appear, switch the game to windowed or borderless.

## Новое
- **FPS в любой игре**: кроме DirectX 10–12 счётчик теперь видит DirectX 9 (Terraria), OpenGL (Minecraft, STALCRAFT) и Vulkan. Кадры берутся из события драйвера ядра Windows о каждом выведенном кадре (проверено на живом ПК: ровно одно на кадр), Windows сама отфильтровывает лишнее — нагрузки на процессор нет.

Важно: поверх игры в *эксклюзивном* полноэкранном режиме Windows рисовать не даёт никому. Если счётчика не видно — переключи игру в оконный режим или «без рамки».
