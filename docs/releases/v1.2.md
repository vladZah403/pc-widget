**Download:** `PC-Monitor.zip` below → unpack anywhere → run `PC-Monitor.exe`.
Windows may say "Windows protected your PC" — the program isn't signed. Click "More info" → "Run anyway".

## New
- **FPS in games** — "FPS 60" in the corner of the game window (DirectX 10/11/12, windowed or borderless)
- **History** — CPU temperature and load for the last hour or day (click the temperature block)
- **Battery wear** and power draw on battery
- **Tray icon** with the menu; hover shows CPU, RAM and temperature
- **Ping to any address** — 1.1.1.1, 8.8.8.8, 9.9.9.9 or your own (a game server, your router)
- **Update check** — the widget tells you when a new version is out (it never installs anything itself)
- **Languages:** English, Ukrainian, German and Russian — as in Windows or from the menu "Язык / Language"

Releases are now built by GitHub Actions from the source in this repository.

## Новое
- **FPS в играх** — «FPS 60» в углу окна игры (DirectX 10/11/12, оконный режим или без рамки)
- **История** — температура и загрузка CPU за час или сутки (клик по блоку температуры)
- **Износ батареи** и расход в ваттах без зарядки
- **Значок в трее** с меню, при наведении — CPU, RAM и температура
- **Пинг до любого адреса** — 1.1.1.1, 8.8.8.8, 9.9.9.9 или свой (сервер игры, роутер)
- **Проверка обновлений** — виджет сам скажет, что вышла новая версия (ничего не ставит сам)
- **Языки:** русский, английский, украинский, немецкий — по языку Windows или в меню «Язык / Language»
