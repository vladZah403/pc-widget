**Download:** `PC-Monitor.zip` below → unpack anywhere → run `PC-Monitor.exe`.
**If you have 1.3 or 1.3.1, install this one by hand** (their update button downloads the new version but can't swap it in — fixed here; from 1.3.2 on the button works).

## Fixed
- **Update in one click didn't finish**: the helper that swaps the folders started inside the program folder, so Windows wouldn't rename it and the old version came back. It now works from outside, and the program itself no longer keeps its own folder as the current one.
- A half-finished update folder is cleaned up at the next start.

## New
- **In games and fullscreen videos** the widget now **hides** by default (Settings → Look: hide / dim / nothing). Ctrl+Alt+W during a game shows it anyway.

## Исправлено
- **Обновление в один клик не завершалось**: помощник, который меняет папки, запускался изнутри папки программы, и Windows не давала её переименовать — возвращалась старая версия. Теперь он работает снаружи, а сама программа больше не держит свою папку текущей.
- Недоделанное обновление убирается при следующем запуске.

## Новое
- **В играх и видео на весь экран** виджет теперь по умолчанию **прячется** (Настройки → Вид: прятать / тускнеть / ничего). Ctrl+Alt+W в игре всё равно его покажет.
