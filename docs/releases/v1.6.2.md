## Fixed
- **Update check failed on a fresh Windows** ("certificate verify failed"): a new Windows fetches root certificates only when a browser needs them, so the widget couldn't verify GitHub. It now carries its own list of trusted roots, next to Windows'.
- **Closing the widget** could log a sensor error (and sometimes crash) because the sensor library was still being read while .NET shut down. It now stops the sensors first, and the window disappears at once.
- With admin rights but without the PawnIO driver, the temperature row showed "CPU —" with no explanation when only the SSD had a temperature. It now says "CPU and GPU: PawnIO needed".
- Intel's iGPU on Core Ultra is shown as "Intel Graphics" instead of just "Graphics".

## For Windows 11
- The log tells more about the Windows 11 taskbar and about drives without a health row, so the taskbar panel and SSD health can be made to work there too.

## Исправлено
- **На свежей Windows не работала проверка обновлений** («certificate verify failed»): новая Windows скачивает корневые сертификаты, только когда они нужны браузеру, и виджет не мог проверить GitHub. Теперь у него свой список доверенных корневых сертификатов вдобавок к списку Windows.
- **При закрытии виджета** иногда появлялась ошибка датчиков (а иногда и сбой): библиотеку датчиков ещё читали, пока .NET уже выгружался. Теперь датчики останавливаются первыми, а окно пропадает сразу.
- С правами администратора, но без драйвера PawnIO в строке температур было «CPU —» без объяснения, когда температуру показывал только SSD. Теперь там написано «CPU и GPU: нужен PawnIO».
- Видеокарта Intel в Core Ultra называется «Intel Graphics», а не просто «Graphics».
