**Download:** `PC-Monitor.zip` below → unpack anywhere → run `PC-Monitor.exe`.

## Fixed
- **No temperatures, GPU load or battery wear after downloading 1.2 / 1.3.** Windows marks files unpacked from a downloaded zip as "from the internet", and .NET refuses to load such DLLs, so the sensor library didn't start. The program now removes that mark from its own DLLs when it starts.
- If the sensor library stops answering, it is opened again instead of staying silent.

If you have 1.2, install 1.3.1 by hand once (unpack, run, "Yes" in UAC); from 1.3 on, updates install in one click.

## Исправлено
- **Не было температур, загрузки видеокарты и износа батареи после скачивания 1.2 / 1.3.** Windows помечает файлы из скачанного zip как «из интернета», а .NET не загружает такие DLL — библиотека датчиков не запускалась. Теперь программа снимает эту пометку со своих DLL при запуске.
- Если библиотека датчиков перестаёт отвечать, она переоткрывается, а не молчит.

Если у тебя 1.2 — поставь 1.3.1 вручную один раз (распаковать, запустить, «Да» в UAC); начиная с 1.3 обновления ставятся одним кликом.
