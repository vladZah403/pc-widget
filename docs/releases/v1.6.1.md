## Faster
- The widget is drawn **30–36% faster** (14 ms instead of 20 per frame) and looks exactly the same.
- **While it is hidden** (Ctrl+Alt+W, tray) **or tucked away during a game**, it no longer redraws itself every second.

## Fixed
- The FPS counter kept the last frames of every closed game in memory until the widget was closed; now it forgets them.
- A damaged history file could break the history charts.
- Alt+F4 on the widget now closes it properly (FPS counter, tray icon, history), and signing out of Windows keeps the last minute of history.

## Safer
- Limits on what comes from outside: the sensor web server's answer and the size of an update archive.
- The widget only ever opens its own release pages.

## Быстрее
- Виджет рисуется **на 30–36% быстрее** (14 мс вместо 20 на кадр) и выглядит точно так же.
- **Когда он спрятан** (Ctrl+Alt+W, значок в трее) **или убран на время игры**, он больше не перерисовывается каждую секунду.

## Исправлено
- FPS-счётчик хранил в памяти последние кадры каждой закрытой игры, пока работал виджет. Теперь забывает их.
- Испорченный файл истории мог сломать графики истории.
- Alt+F4 на виджете теперь закрывает его правильно (FPS-счётчик, значок в трее, история), а при выходе из Windows сохраняется последняя минута истории.

## Надёжнее
- Ограничен размер того, что приходит извне: ответ веб-сервера датчиков и архив обновления.
- Виджет открывает только страницы своих релизов.
