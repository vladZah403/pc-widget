**Скачать:** `PC-Monitor.zip` ниже → распаковать в любую папку → запустить `PC-Monitor.exe`.

Windows может показать «Система Windows защитила ваш компьютер» — программа не подписана сертификатом. Нажми «Подробнее» → «Выполнить в любом случае».

## Новое
- Частота и мощность процессора под графиком (с правами администратора)
- График сети за последнюю минуту: приём — вверх, отдача — вниз
- Сколько ещё проработает батарея
- Меню «Показывать» — можно убрать лишние строки
- Меню «Предупреждения» — свои пороги перегрева, памяти и батареи
- Вставленная флешка появляется в виджете сама
- Крестик закрывает виджет только со второго нажатия

## Безопасность и надёжность
- По умолчанию виджет работает без прав администратора. Температуры включаются в меню: «Права администратора (температуры)»
- В этом режиме программа копирует себя в `C:\Program Files\PC-Monitor` и с правами администратора запускается только оттуда — подменить её файлы без прав администратора нельзя. Автозапуск с правами администратора — тоже только для этой копии
- Настройки и лог ошибок лежат в `%APPDATA%\PC-Monitor`
- Сборка — папка вместо одного большого exe: запускается быстрее

Проверено на Windows 10. На Windows 11 мини-панель на панели задач по умолчанию выключена (включается в меню).

Внутри используется [LibreHardwareMonitorLib](https://github.com/LibreHardwareMonitor/LibreHardwareMonitor) (лицензия MPL-2.0, исходный код — по ссылке).
